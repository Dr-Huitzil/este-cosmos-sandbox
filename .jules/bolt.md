## 2025-02-14 - Optimize Fuel Utility Functions to Prevent O(N^2 log N) Degration
**Learning:** Utility functions (like `calculateMPG`) processing collections should NOT sort data internally when they might be called within render loops (e.g., table `.map` operations or `useMemo` hooks calculating history). This causes an O(N^2 log N) performance degradation, repeatedly sorting large datasets unnecessarily.
**Action:** The architecture of this application correctly provides globally pre-sorted data arrays (like `sortedFuelEntries` via `FleetContext` / `useFuel`) for child components to use. Always ensure utilities accept and rely on these pre-sorted arrays, rather than sorting internally. When updating components or hooks to use this pattern, carefully update the passed dependencies to the pre-sorted collections instead of generic ones (e.g., using `sortedFuelEntriesRef.current` instead of `fuelEntriesRef.current`).

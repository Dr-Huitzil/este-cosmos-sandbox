## 2024-06-13 - [O(N^2 log N) Bottleneck in Table Rendering]
**Learning:** React memoization inside rendering loops fails hard when dealing with complex object sets being implicitly passed down and sorted per component. `FuelLogTable`, `ServiceLogTable`, and `ReclaimLogTable` were individually re-sorting their input arrays (O(N log N)), and utility functions like `calculateMPG` were also performing an O(N log N) sort internally. Because `calculateMPG` was being called for every row in the UI map loop, this resulted in an O(N^2 log N) performance degradation for list renders.
**Action:** When working with collections across multiple components/utilities, apply pre-sorting at the highest feasible level (e.g., inside the Context via `useMemo`) and strictly avoid internal `.sort()` calls inside utility functions or child component map loops. Components and utility functions must expect properly pre-sorted arrays as props/arguments.

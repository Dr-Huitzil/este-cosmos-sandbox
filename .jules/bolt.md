## 2024-05-30 - Remove O(N^2 log N) Bottleneck in utility mapping functions
**Learning:** Pure utility functions (like `calculateMPG` or `calculateHealth`) that iterate or sort data collections can cause massive, hidden $O(N^2 \log N)$ performance degradation when called inside UI `.map()` loops or iterative data transformations if they perform their own `.sort()` internally on each call. Because sorting is relatively slow and arrays might be large (like fuel logs), this completely breaks the React rendering cycle's efficiency.
**Action:** When working on performance optimizations in this codebase, explicitly look for `.sort()` calls inside loops or utility functions that are invoked during renders. Always remove internal sorts from utility functions and instead rely on the `FleetContext` pre-sorted arrays (such as `sortedFuelEntries`) as arguments. This changes the complexity from $O(N^2 \log N)$ to $O(N^2)$, and leverages the memoized sort already happening in the custom hooks.

## 2024-03-24 - [Avoid Redundant Sorting in Utilities Used Within Render Loops]
**Learning:** This codebase uses an architectural pattern where data arrays (like fuel entries) are pre-sorted (newest-first) at the context/hook level (e.g., `FleetContext`, `useFuel`). Utility functions like `calculateMPG` that process these collections within render loops (like table row mapping) must rely on this pre-sorting. Performing internal `.sort()` operations inside these utilities causes `O(N^2 log N)` performance degradation during render cycles.
**Action:** When creating or optimizing utility functions that process collections, check if the architecture already provides them as pre-sorted. Accept the generic array prop (e.g., `entries`) and avoid internal sorting to maintain O(N) performance, especially if the utility is called repeatedly within a render loop.

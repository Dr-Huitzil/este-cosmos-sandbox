## 2024-07-05 - Avoid Redundant Sorting in UI Iterations
**Learning:** `calculateMPG` was originally designed to accept all elements and do an internal `O(N log N)` sort operation. When this function was called within map functions iterating over arrays, it incurred `O(N^2 log N)` performance degradation. Components (`fuelLogTable`, `AnalyticsContext`) also assumed or re-performed sorts implicitly.
**Action:** When working with collections and performance-sensitive map operations on the frontend, utility functions like `calculateMPG` should rely strictly on globally pre-sorted data provided by Contexts (`useFleet().sortedFuelEntries`) and state to reduce complexity from `O(N^2 log N)` to `O(N)`. Never perform sorts directly inside helper functions intended to be called in a loop.

## 2024-05-18 - [Optimizing O(N^2 log N) calculations on array elements]
**Learning:** Functions designed to iterate across large datasets inside of UI render loops or list iterators (like mapping through `fuelLogTable`) can lead to performance degradation if they run independent O(N log N) sorts inside the loop. In `calculateMPG`, sorting an array of `N` items internally, while inside a loop over `N` items, creates an O(N^2 log N) bottleneck.
**Action:** Always pre-sort arrays at the call site (preferably memoized with `useMemo` in React) and pass the pre-sorted array to the utility function instead. This brings the time complexity down to O(N). When writing utility functions, explicitly document if they require a pre-sorted array to prevent future developers from adding an internal sort.

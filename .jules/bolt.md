## 2024-05-31 - [Remove redundant N log N sort in calculateMPG]
**Learning:** Utility functions that process lists (like `calculateMPG` checking historical efficiency) can cause O(N^2 log N) degradation if they internally sort the lists while being called in an O(N) map or loop (such as inside a table render or map over history). The `FleetContext` correctly provides globally pre-sorted data arrays to child components as an architectural pattern to avoid this, but utility functions need to be written to explicitly leverage these pre-sorted arrays rather than performing the sorting themselves.
**Action:** Always ensure that data arrays passed into utility functions within renders or loops are pre-sorted at the call site or context level, and modify the utility function to require and expect pre-sorted input instead of internally sorting it. Document this requirement explicitly in the utility function's JSDoc.

## 2024-06-23 - Prevent O(N^2 log N) degradation in render loops
**Learning:** Utility functions (like `calculateMPG`) that process collections must not perform internal `.sort()` operations if they are called inside render loops or component mapping functions. In this codebase, table components and utility calculations assume that the provided entry arrays (like `sortedFuelEntries`) are already pre-sorted newest-first by date via Context or memoized state. Internal sorting causes severe O(N^2 log N) performance degradation.
**Action:** When creating or optimizing utility functions that require chronological data, always pass them pre-sorted arrays (e.g., using `memoizedDateSortedEntries` or the `latest ref` pattern like `sortedFuelEntriesRef`) and avoid any internal `Array.prototype.sort()` calls.

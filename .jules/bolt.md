## 2024-06-10 - O(N^2 log N) Bottleneck in React Render Loop
**Learning:** Utility functions (like `calculateMPG`) that process collections inside array iterations (like `map`) shouldn't perform internal `.sort()` operations when the base array remains constant. In this codebase, the standard pattern is that `FleetContext` (via hooks like `useFuel`, `useService`, etc.) calculates pre-sorted data arrays and memoizes them with `useMemo`. Components receive these globally pre-sorted collections or derive locally pre-sorted arrays once. Calling utility functions that internally sort the entire array for each element being mapped leads to O(N^2 log N) performance degradation as the data grows, particularly for fuel telemetry calculation.

**Action:** When creating or refactoring data processing functions meant to be used within UI rendering loops, design them to accept *pre-sorted* arrays. Always ensure `useMemo` is used to sort arrays exactly once at the highest appropriate component or context level.

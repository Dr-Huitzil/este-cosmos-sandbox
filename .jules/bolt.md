## 2024-11-23 - Avoiding O(N^2 log N) Render Bottlenecks in Data Grids
**Learning:** Utility functions (like `calculateMPG`) called inside loop iterations (e.g., mapping over rows in a table) that internally perform a `.sort()` operation create a massive performance bottleneck. In this specific application, iterating through $N$ log entries and sorting the array of $N$ entries within each loop caused an $O(N^2 \log N)$ complexity.
**Action:** When a utility function requires sorted collections, it must expect a pre-sorted array as an argument. The consumer of the utility function (React component or context provider) should leverage the global `FleetContext` patterns to access `useMemo`-backed pre-sorted arrays, passing them into the utility to ensure sorting only occurs $O(N \log N)$ times globally.
